My programming experience

1 October 2026

Before the HZ I mostly tinkered. I worked on a 'utility' client for Minecraft Java, experimented with Linux, and modded devices like my 3DS. I learned from trial and error, by looking things up online, and just experimenting.

Previously I've followed different free courses via youtube and websites such as freecodecamp.org. There I learned the basics about Python, Javascript, CSS and HTML. My coding experience is still very shallow.

What I learned building this website

  • Writing a large quantity of HTML pages with semantic tags.
  • Using Javascript on my own website for the first time.
  • Styling pages with CSS.
  • Using Git and GitHub Pages to publish my site.
  • Developing a better understanding of CSS, after doing more research.

Whenever I am programming something I try to break the process down into separate layers. Looking at the code step by step, and confirming that each step is correct is something that I've used during the development of this website as well. This makes it easier to troubleshoot errors.
